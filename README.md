# korean-story-world
K-Storyteller Library (한국어 월드 자료실) — 학생용 자료실 사이트 (GitHub Pages)

- 항목 추가: `data.js` 한 파일만 고치면 돼요. 맨 위에 예시가 있어요.
- 삽화: 원본을 `originals/`에 넣고 `shrink-images.bat`을 더블클릭하면 `img/`에 webp(150KB 이하)로 들어가요.
  `originals/`는 저장소에 올라가지 않아요(용량 때문에). 원본은 이 컴퓨터에 따로 잘 보관하세요.
- 게임 "나라 엄마의 하루": `games/nara-mom-in-law/` (첫 화면에는 없고, 주소로 따로 열어요)
